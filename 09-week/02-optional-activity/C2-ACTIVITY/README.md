Data & cleaning
This dataset contains industrial sensor metrics collected from various mechatronic systems and equipment to monitor their operational health. During the data cleaning phase, missing values in numerical columns such as temperature and vibration were handled through mean imputation, and text-based numeric fields were successfully converted to float data types. Duplicate rows and records containing null identification fields were completely removed to maintain data integrity. After applying these cleaning steps, the dataset was successfully standardized, reducing data anomalies and structural errors. Finally, analytical queries were performed using Pandas to filter critical temperature thresholds and aggregate performance metrics by equipment status.
